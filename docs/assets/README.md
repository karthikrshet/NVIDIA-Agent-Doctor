# Documentation assets

`nvidia-agent-doctor-banner.png` is the README hero image supplied by the
project maintainer. It is presentation artwork, not evidence of NVIDIA
affiliation, certification, or endorsement.

The README must retain its adjacent independent-project disclaimer. Before a
public release, the maintainer must confirm that publication of all artwork and
trademarks represented in the image is permitted for the intended use.

`linkedin-launch-card.svg` is an editable 1200 × 627 social-media launch card.
It intentionally avoids NVIDIA logos and product artwork, and includes the
project's independent-project disclaimer. It may be exported to PNG before
uploading to platforms that do not accept SVG files.
